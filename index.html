Thesis

The world has 10× cognitive tools. Almost nobody uses them.

The leverage isn’t the model. It’s the operator. Five engineers with the right primitives can ship what two hundred can’t — and that gap is the entire opportunity.

We build infrastructure, not applications. Every system we ship is meant to outlive the current model cycle, the current framework, and the current hype wave.

Our products are edge-native: Cloudflare Workers, Pages, D1, R2, and KV run our entire fleet. No Kubernetes. No idle boxes. Compute is paid for only when it does work, and data lives where the user is.

Our work is India-first. 1.4 billion people, 22 scheduled languages, the hardest geocoding problem on Earth. If a system works here, it works anywhere.

And our default mode is private. Code stays on your machine. Models run on your box. The network is a courier, not a confessor.

5 engineers shipping what 200 can’t. That isn’t a boast. It’s a measured output, and it’s the only metric that compounds.
— Pronit Das, Founder

Operating principles

6 things we won’t compromise on.

Not values for a wall. Operating constraints that shape what we build, who we hire, and what we say no to.

01

Infrastructure over applications

If it can’t outlive the current model, it isn’t a product. It’s a demo with a billing plan.

02

Leverage over headcount

5–12 elite operators outperform 200 average ones. Every hire is judged on leverage-per-engineer, every quarter.

03

Trajectory over income

We optimise for the 10-year arc, not the next 90 days. Cash is fuel, not a finish line.

04

Inevitability over attention

If the work is real, attention follows. If we need attention, the work isn’t real yet.

05

Privacy is architecture

Not a feature, not a policy, not a marketing line. The data path is the product. If it leaves the box, the design is wrong.

06

India is the bet

1.4B people, 22 languages, the hardest geocoding problem on Earth. The next decade of infrastructure is built here.
